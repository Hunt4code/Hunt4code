## 📌 Featured Projects

### 🤖 [Agentic-RAG](https://github.com/Hunt4code/Agentic-RAG)
> Production agentic RAG system with LangGraph, Anthropic Claude, and ChromaDB

- Multi-step reasoning with conditional edge routing and relevance grading
- Ingests PDFs, DOCX, and URLs — evaluated via RAGAS (faithfulness 0.85, answer recall 0.80)
- Deployed as a Streamlit app with real-time query tracing
- **Stack:** LangGraph · Claude · ChromaDB · HuggingFace · Streamlit

---

### 🏦 [CreditLens](https://github.com/Hunt4code/creditlIens)
> Explainable credit intelligence platform for CFPB-compliant lending decisions

- Extends production credit risk models with SHAP and DiCE counterfactual explanations
- Claude-powered narrative summaries of model decisions for non-technical stakeholders
- Built on real financial services ML work from AWS/SageMaker pipelines
- **Stack:** Python · SHAP · DiCE · Anthropic Claude · Scikit-learn · AWS
